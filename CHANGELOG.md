# Changelog

## 1.5.0
- **Terminal sessions:** Claude Code is now recognised however it's installed (desktop app, terminal installer, Homebrew, npm), with its node/uvx MCP helpers grouped under it.
- Optional auto-pause for terminal sessions (Settings → Pause unused Claude sessions → *Include sessions in a terminal*). The tab then shows how to resume: `claude --continue`.
- Terminal sessions get their last-used time from their folder's conversation history.

## 1.4.0
- **Copy diagnostics** button (Settings) and `--diagnostics` option for bug reports — no personal names included.
- Automated tests for how processes are grouped, run on every change.
- Homebrew updates itself after each release.
- Issue templates, pull request checklist, code of conduct, security policy.

## 1.3.4
- Panel closes when you click anywhere outside it; always opens on the main page.
- Dropdowns and the menu bar item keep a fixed width, so nothing shifts.
- History scrolls through 7 days of events, grouped by day.
- Update check: never, daily or weekly. Settings grouped into cards.
- "Restart Claude when I step away" replaces the overnight restart.
- Hover any symbol to see its name.

## 1.3.0
- Settings: options appear under each switch; Advanced (lag sensitivity, update speed, hide small items, unused-app hours); choose which tips to show; manage ⚡ apps; reset to defaults.

## 1.1.0
- History screen, leak detection, Disk screen, Claude session titles and last-used times, smart auto-pause, notification buttons, first-run setup, menu bar styles, ⌥⌘M shortcut.

## 1.0.0
- First public release.
