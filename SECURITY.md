# Security

Mac Memory Monitor can quit apps and stop processes on your Mac, so security matters.

**Please don't report security problems in public issues.** Use GitHub's private reporting instead: the repository's **Security** tab → **Report a vulnerability**. You'll get a reply within a few days.

What the app does and doesn't do:
- It never connects to the internet, except the update check you can turn on (it asks GitHub for the latest version number).
- It only reads information about processes; it never reads your files, except the Claude Code conversation files it reads for session titles and last-used times.
- It only stops or quits something when you click, or when you've switched on an automatic feature.
